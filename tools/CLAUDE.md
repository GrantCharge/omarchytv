# tools: index

- `tv.py`: main TV control script.
- `disable.sh`, `disable.ps1`, `restore.sh`, `restore.ps1`: switch TV packages off and back on.
- `backup-state.sh`, `reboot-check.sh`, `mem-compare.sh`, `private-dns.sh`: checks and backups.
- `b64push.py`, `pulse-tv-data.py`, `pulse-tv-scenes.py`, `racing_calendar.py`: data helpers.
- `requirements.txt`: Python needs. `adbkey/`: ADB key folder. Do not print or copy its contents.
